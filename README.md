# banktrail# FinPro Bank Data Analytics Project

## Project Overview
Designed a data management and reporting system for FinPro Bank.

## Tools Used
- PostgreSQL
- SQL
- Excel
- Tableau

## Key Work
- Designed database schema and ERD
- Cleaned and prepared data
- Created SQL queries
- Built reports and dashboards
- Analyzed customer and transaction data

## Reports
- Customer Closing Balance
- Country-wise Transactions
- Customer Average Age
- Branch Transaction Analysis

## Skills Demonstrated
SQL | Data Modeling | Excel | Tableau | Data Visualization
